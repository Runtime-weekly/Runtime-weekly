## How we share work

Code and guides live in the tutorial library. Articles and newsletters live in the
reading archive. Each runnable guide includes synthetic examples, setup steps,
sources and limitations. A recorded result is evidence for that run, not a promise
of the same accuracy or speed on every machine.

Have a correction or a question? Use the relevant repository's Issues page.
Please share a small synthetic example rather than private documents or logs.
